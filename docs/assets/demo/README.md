# VaaniQ complete demo (one file)

`VaaniQ_Examiner_Demo.mp4` — speakers on.

For each of Hindi, Marathi, Tamil:

1. Hear HUMAN (Kathbath) speech with a live spectrogram.
2. Then the calculated **REAL** result: P(real)/P(fake), analysis, native transcript, English translation, waveform, spectrogram.
3. Hear AI (IndicSynth) speech with a live spectrogram.
4. Then the calculated **FAKE** result with the same full panel.

Then dashboard, RQ4 calibration graphs (ECE, Brier, reliability, coverage), explainability,
experiments RQ1-RQ4, limitations, and API documentation.
